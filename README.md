# Bubble Reef

A small bubble shooter in a single HTML file. Open `index.html` in any browser.

- Aim with the mouse or a finger, release to shoot. Bubbles bounce off the side walls.
- Match 3 or more of one color to pop them. Bubbles left hanging fall off for bonus points.
- Every few shots that don't pop anything, a new row drops in. If bubbles cross the red line, the game ends.
- Clear the board to move to the next level (more colors, more rows, fewer shots between new rows).
- Keys: ← → aim, Space shoot, X swap with the next bubble.
